MediCare Plus — Responsive Hospital / Clinic Website

Included:
- index.html (HTML5 + CSS3 + Bootstrap 5 + vanilla JavaScript)

Run:
1. Extract the ZIP.
2. Open index.html in VS Code.
3. Use Live Server, or open the file in your browser.
Internet access is needed for Bootstrap and Google Fonts CDN resources.

Before publishing:
- Replace sample phone, email, address, opening hours, and clinician profile details with verified information.
- Replace 919999999999 in both WhatsApp URLs with the clinic's real WhatsApp number.
- Confirm the actual services offered and remove any that do not apply.
- The appointment form prepares a WhatsApp message. It does not save patient data or automatically confirm appointments.
- Do not use this demo form to collect sensitive medical details.
- This template is not an emergency medical service.
